You can read Swift in a browser. Shipping an iPhone, Mac, or Apple Watch app happens on a Mac. Xcode, the Simulator, code signing, and the upload to App Store Connect are Apple's tools, and they run on macOS.

Get that machine ready once. Every later lesson is then practice.

## What to install

You need a Mac whose macOS version can run the current Xcode. The Xcode page on the Mac App Store states the minimum. Install Xcode from that store. It is free, and it includes the Swift compiler, previews, Simulators, Instruments, and the organizer that uploads builds.

Sign in to Xcode with an Apple Account under Settings, Accounts. A free account runs apps in the Simulator and, with limits, on a device you personally own. A paid Apple Developer Program membership is what you need later for TestFlight and the stores. Do not buy it on day one.

Swift Playground, on Mac or iPad, is a good place for the next few language lessons if a full app target feels heavy. You will still return to Xcode for SwiftUI.

## Prove the three templates

Create a project you are allowed to delete. Choose File, New, Project, then iOS, App. Set the interface to SwiftUI and the language to Swift. Leave storage off for this first run.

```swift
import SwiftUI

@main
struct FirstLightApp: App {
    var body: some Scene {
        WindowGroup {
            Text("Hello from the Simulator")
                .padding()
        }
    }
}
```

Press Run and pick an iPhone Simulator. The first launch may download a device runtime. When the text appears, the toolchain works.

Repeat the new-project steps for a macOS App and a watchOS App. Run each one. You are only proving that three templates exist.

</Callout>

## Exercise

Install Xcode. Run the throwaway iOS app, then the macOS and watchOS templates. Rename the text in each so you know which target you launched.

<Solution>

If the iOS Simulator never appears, open Xcode, Settings, Components, and download an iOS platform. If a physical device is selected in the run destination menu, switch the destination to a Simulator. The watch target needs both a watch and a paired iPhone runtime.

</Solution>
