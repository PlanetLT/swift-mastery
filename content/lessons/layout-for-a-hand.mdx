An iPhone screen is a portrait column held in one hand. The primary action sits where a thumb can reach it, usually low. The title sits where the eye starts, usually high. SwiftUI stacks are enough for that if you choose spacing instead of hard-coded frames.

## A column with a reachable action

```swift
import SwiftUI

struct HandLayout: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            Text("Today")
                .font(.largeTitle)
            Text("Three lessons left in the foundation. One of them needs a Mac, and you are already on one.")
                .font(.body)
                .foregroundStyle(.secondary)
            Spacer(minLength: 24)
            Button("Continue") {}
                .buttonStyle(.borderedProminent)
                .frame(maxWidth: .infinity)
        }
        .padding()
        .safeAreaPadding(.bottom)
    }
}
```

`Spacer` pushes the button down. `frame(maxWidth: .infinity)` makes the button a full-width target without pinning it to a magic point size. `safeAreaPadding` keeps it above the home indicator. If you ignore the safe area, do it only for a background color, never for a control.

Use the system text styles: `.largeTitle`, `.body`, `.caption`. They follow the person's type size. A `.font(.system(size: 17))` does not.

<Callout title="Where people stall">

They design at one phone size in the preview and ship clipped text on a smaller phone or with larger accessibility type. Add a second preview, and turn on a larger Dynamic Type size in the environment. If the button disappears, the layout is not finished.

</Callout>

## Exercise

Build this screen. Add a preview with `dynamicTypeSize(.accessibility3)`. Make the paragraph and the button both remain reachable by scrolling if they no longer fit.

<Solution>

Wrap the stack in a `ScrollView` when you test large type. Keep the button inside the scroll content, or pin it with `safeAreaInset(edge: .bottom)` so it stays visible while the text scrolls. `safeAreaInset` is the better professional shape: the action remains on screen, the words move.

</Solution>
